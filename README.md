# Secure Enterprise AI — starter project

Учебный каркас для take-home задания на роль Forward Deployment Engineer.

## 1. Установка

Python 3.11 или 3.12 рекомендуется.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
```

## 2. Запуск API

```bash
uvicorn app.main:app --reload
```

- Health: http://127.0.0.1:8000/health
- Readiness: http://127.0.0.1:8000/ready
- Swagger: http://127.0.0.1:8000/docs

## 3. Запуск тестов

```bash
pytest -q
```

Часть тестов намеренно должна выявить незавершённые требования. Это список задач, а не доказательство production-ready безопасности.

## 4. Что реализовать по порядку

1. Исправить тест на пробелы в вопросе (валидация должна отклонять пустой после strip вопрос).
2. Добавить загрузку и хранение документов с метаданными.
3. Реализовать chunking и retrieval; сначала можно использовать простой поиск по словам.
4. Фильтровать документы по правам пользователя ДО retrieval.
5. Подключить LLM через отдельный адаптер и заставить ответ воздерживаться от ответа без доказательств.
6. Возвращать только реальные цитаты из доступных документов.
7. Добавить тесты prompt injection, сбоя модели/хранилища, неверных форматов и лимитов.
8. Усилить Docker/Kubernetes для offline/on-prem deployment.

## 5. Важные ограничения стартового проекта

- Аутентификация пока учебная: `username` передаётся параметром/полем запроса. В production нужны проверяемые identity claims (например, OIDC/JWT) и серверная авторизация.
- In-memory хранилище не переживает перезапуск и не предназначено для production.
- LLM ещё не подключена. Не отправляйте реальные секреты или персональные данные в тестовые документы.
- Не называйте систему безопасной для production, пока не реализованы аутентификация, аудит, секреты, ограничения ресурсов и threat model.
